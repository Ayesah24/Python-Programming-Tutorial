1. Introduction to Python

Python is a high-level, interpreted programming language known for its simple and readable syntax. It is commonly used for web development, data analysis, automation, artificial intelligence, and many other applications.

Why Learn Python?

  • Easy to learn and understand
  • Simple and readable syntax
  • Useful for beginners and professionals
  • Used in many areas of technology
  • Has a large community and many libraries
Tip: Practice writing small Python programs regularly to improve your programming skills.

2. Basic Python Syntax

Python uses indentation to organize blocks of code. Unlike some programming languages, Python does not require curly brackets for code blocks.

3. Variables

Variables are used to store information in a program. In Python, you can create a variable by giving it a name and assigning a value.

Example

name = "Christian"
```

age = 19

print(name)
print(age)
```

In this example, name stores text while age stores a number.

Common Data Types

  • String: Text such as "Hello"
  • Integer: Whole numbers such as 10
  • Float: Decimal numbers such as 3.14
  • Boolean: True or False values
name = "Alice"
```

age = 20
height = 1.65

4. If-Else Statements

Conditional statements allow a program to make decisions based on whether a condition is true or false.

Example

age = 18
```

if age >= 18:
print("You are an adult.")
else:
print("You are a minor.")
```

The if statement checks the condition. If the condition is false, the else statement runs.

5. Loops

Loops allow you to repeat a block of code multiple times. Python commonly uses for and while loops.

For Loop

for number in range(5):
print(number)

This program prints the numbers from 0 to 4.

While Loop

count = 1
```

while count <= 5:
print(count)
count += 1
```

6. Functions

A function is a reusable block of code that performs a specific task.

Example

def greet(name):
print("Hello, " + name)
```

greet("Christian")
```

The def keyword is used to create a function. The function can then be called whenever it is needed.
